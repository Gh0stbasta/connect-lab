# ADR-002

## Title

Single Environment Strategy

## Status

Accepted

## Context

Das Projekt dient als persönliches Lernlabor.

## Decision

Es wird zunächst nur eine Umgebung betrieben:

lab

Keine Trennung nach:

- dev
- test
- prod

## Consequences

### Vorteile

- Weniger Komplexität
- Niedrigere Kosten
- Schnellere Lernkurve

### Nachteile

- Keine Umgebungstrennung
